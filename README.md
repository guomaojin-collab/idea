# idea

**Catch it before it's gone.**

A calm, ADHD-friendly idea capture app built around one principle: capture first, organize later.

## V1 prototype
- Frictionless quick capture
- Local persistence in the browser
- Lightweight automatic thought typing
- Inbox / brain dump
- Today view with limited resurfacing
- Idea Universe visual prototype
- Responsive mobile-first navigation

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.
